Ejemplo 3: Reporte de Seguridad

JSON para registrar:
{
  "tipo": "Seguridad",
  "descripcion": "Presencia de perros callejeros en las cercanías de la escuela. Esto representa un riesgo para los niños que se dirigen a clase. Se recomienda captura y cuidado de los animales."
}

---

Cómo registrar reportes:
1. Abre Thunder Client en VS Code
2. Crea solicitud POST
3. URL: http://localhost:3000/reportes
4. Body → JSON
5. Pega uno de los ejemplos anteriores
6. Click en Send

El servidor asignará automáticamente un ID único a cada reporte basado en su posición en el array.
